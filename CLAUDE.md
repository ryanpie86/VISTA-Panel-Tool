# Project conventions

- **UI screenshots**: `README.md` has a "UI Features" section showing the
  current web UI. Whenever a push changes the UI (new screen, layout,
  button, flow), re-capture the affected screenshots and update that
  section in the same push. See `docs/screenshots/README.md` for how.
- **PR + merge every change**: this project is early-stage (solo repo
  owner, no other reviewers yet). For every change, open a PR from the
  working branch to `main` and merge it immediately — don't leave work
  sitting on an unmerged branch/PR waiting for review. Revisit this once
  the project is further along and a real review step is wanted.
